Dependency rules

  • The view MUST depend on the official bridge, not a local protocol copy.
  • Node-only shell/server modules MUST NOT enter the browser view bundle.
  • The MCP boundary MUST remain narrower than the general trusted Renderify source APIs: source-mode payloads run only inside @renderify/frame.
  • Server tool authorization MUST remain outside the view.

Boundary diagram

What this shows: only validated RuntimePlan data crosses from MCP results into the offline runtime; server effects return through an explicit host proxy. Source-mode apps add a second path in which validated source goes to a frame nested in the view, and its allowlisted actions use the same host proxy.
